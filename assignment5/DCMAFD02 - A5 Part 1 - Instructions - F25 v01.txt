Understanding Naming Conventions
(YYY is last three characters of your userid KC03YYY)

BMS source members
- INQSYYY is mapset name for Customer Inquiry program

CBL source members - programs
- CMINQYYY for Customer Inquiry Program
- CMFLOYYY for CMFYYY VSAM file data load program

CBL source members - cobol COPY libraries
- ATTR is copy file for screen attribute definitions used on CICS screens
- DFAID is system copy file that is provided from system libraries 
(THIS FILE YOU DO NOT NEED COPIED TO YOUR USERID)
- ERRORSWS is copy file for variables used to handle ABENDs and other errors
- INQSYYY is copy file from generate of BMS mapset using JCL INQSBYYY
- CMFWSREC is copy file for record layout of CMFYYY VSAM file
- CMFWSSTS is copy file for status variables related to CMFYYY VSAM file
- CMFOPEN is copy file containing open paragraph for CMFYYY VSAM file
- CMFCLOSE is copy file containing close paragraph for CMFYYY VSAM file
- RESPTEXT is copy file containing paragraph to translate errors into text 
- TERMMSG is copy file containing paragraph to send termination message
- HDLABEND is copy file containing abend handling paragraph 

JCL source members 
- CMINQYYY is JCL to compile/LKED Customer Inquiry Program
- INQSBYYY is JCL to generate BMS mapset for Customer Inquiry Program
- DFHZITCL is JCL subroutine used by CMINQYYY JCL 
during compile/LKED of Customer Inquiry Program

JCL source members with HHHJJYYY names for VSAM file
- HHH is file short name of the VSAM file
o CMFYYY for Customer File

- JJ is literal that represents the task the JCL is for
1. CC is JCL to create clusters in VSAM file
2. LO is JCL to compile/LKED and execute VSAM load program
3. FF is JCL to create flat file from VSAM file
4. FL is JCL to list catalog information about VSAM file

Additional Notes:

- Using VISTA TN3270, type CICS and press return
to get to the CICS environment
(there is no specific logon to CICS environment)

- To clear the screen press 'Pause Break' on keyboard, 
or select Window on menu, then Show Key Pad, 
then click Clear button on Key Pad

- You can choose to edit the tool bar and add the Clear button
After opening Vista session connected to mainframe, 
on Menu, select Options, then select Toolbar Edit, click on WORDS tab, drag Clear button to desired location on toolbar, then click OK
 

- CEMT SET PROGRAM(CMINQYYY) DISABLED
CEMT SET PROGRAM(CMINQYYY) ENABLED
These will stop/start a program when function keys not working.

- CECI SEND MAP(INQMYYY) MAPSET(INQSYYY)
This tests the map in the mapset to be sure it is available.

- CEMT SET FILE(CMFYYY) OPEN
CEMT SET FILE(CMFYYY) CLOSED
These will manually open/close a VSAM file
to see if the VSAM file has been setup correctly in CICS, and 
confirm CICS is connected to the actual VSAM file you created earlier.
This does not replace the open/close logic you need to add to the program for the VSAM file.
