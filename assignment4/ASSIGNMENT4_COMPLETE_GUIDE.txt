4. CICS SETUP AND TESTING COMMANDS
================================================================================

STEP 4.1: CONNECT TO CICS
--------------------------
1. Open VISTA TN3270 emulator (or your 3270 terminal emulator)
2. Connect to the mainframe
3. Log in with your credentials
4. Enter CICS transaction: CICS
   (This connects you to the CICS region)

STEP 4.2: DEFINE YOUR RESOURCES IN CICS
----------------------------------------
Enter each command below, pressing ENTER after each:

COMMAND 1: Define the MAPSET
-----------------------------
CEDA DEFINE MAPSET(MNUSFE1) GROUP(DCMAFD02)

PRESS ENTER
You'll see a panel - fill in:
- MAPSET: MNUSFE1
- GROUP: DCMAFD02
- Press PF5 to save

COMMAND 2: Define the PROGRAM
------------------------------
CEDA DEFINE PROGRAM(99MNUFE1) GROUP(DCMAFD02) TRANSID(9FE1)

PRESS ENTER
You'll see a panel - verify:
- PROGRAM: 99MNUFE1
- GROUP: DCMAFD02
- TRANSID: 9FE1
- Press PF5 to save

COMMAND 3: Define the TRANSACTION
----------------------------------
CEDA DEFINE TRANSACTION(9FE1) GROUP(DCMAFD02) PROGRAM(99MNUFE1)

PRESS ENTER
You'll see a panel - verify:
- TRANSACTION: 9FE1
- GROUP: DCMAFD02
- PROGRAM: 99MNUFE1
- Press PF5 to save

STEP 4.3: DISPLAY AND INSTALL RESOURCES
----------------------------------------
COMMAND 4: Display all your resources
--------------------------------------
CEDA DISPLAY GROUP(DCMAFD02) ALL(*FE1*)

This shows all resources with FE1 in the name

COMMAND 5: Install each resource
---------------------------------
For each resource shown (MAPSET, PROGRAM, TRANSACTION):
1. Type "I" (Install) next to the resource
2. Press ENTER

OR install them individually:
CEDA INSTALL MAPSET(MNUSFE1) GROUP(DCMAFD02)
CEDA INSTALL PROGRAM(99MNUFE1) GROUP(DCMAFD02)
CEDA INSTALL TRANSACTION(9FE1) GROUP(DCMAFD02)

STEP 4.4: TEST THE MAP DISPLAY
-------------------------------
CECI SEND MAP(MNUMFE1) MAPSET(MNUSFE1)

PRESS ENTER - You should see your menu screen!

STEP 4.5: SET NEWCOPY FOR PROGRAM
----------------------------------
CEMT SET PROG(99MNUFE1) NEWCOPY

This ensures CICS loads the latest version of your program

STEP 4.6: TEST YOUR TRANSACTION
--------------------------------
1. Clear the screen (use CLEAR key or PA2)
2. Enter: 9FE1
3. Press ENTER

YOU SHOULD SEE:
                         M A I N    M E N U
                         ==================

               CHOICE 1 - ENTER NEW STUDENT

               CHOICE 2 - INQUIRE BY STUDENT NUMBER

               CHOICE 3 - CHANGE OR DELETE EXISTING STU

               CHOICE 4 - SEARCH BY STUDENT NAME

8. TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: BMS compilation fails
-------------------------------
SOLUTION:
□ Check that MNUSFE1 exists in KC03FE1.DCMAFD02.A4.MNU.BMS
□ Verify all YYY are replaced with FE1
□ Check for typos in BMS syntax
□ Ensure continuation characters (*) are in column 72

PROBLEM: COBOL compilation fails
---------------------------------
SOLUTION:
□ Check that 99MNUFE1 exists in KC03FE1.DCMAFD02.A4.MNU.COBOL
□ Verify COPYBOOK datasets exist
□ Check that MNUSFE1 copybook was created by BMS assembly
□ Review compiler error messages in job output

PROBLEM: "MAPFAIL" error when testing
--------------------------------------
SOLUTION:
□ Ensure BMS map was compiled successfully
□ Verify MAPSET was installed in CICS
□ Check map names match exactly (MNUMFE1, MNUSFE1)
□ Try: CEMT SET PROG(99MNUFE1) NEWCOPY

PROBLEM: "Program not found" in CICS
-------------------------------------
SOLUTION:
□ Verify program compiled successfully (MAXCC=0)
□ Check that program was installed: CEDA INSTALL PROGRAM(99MNUFE1)
□ Ensure TRANSACTION points to correct program
□ Use: CEMT INQUIRE PROGRAM(99MNUFE1) to check status

PROBLEM: Screen doesn't display correctly
------------------------------------------
SOLUTION:
□ Check terminal size is 24x80
□ Verify BMS positions are correct
□ Send map manually: CECI SEND MAP(MNUMFE1) MAPSET(MNUSFE1)
□ Check for LOW-VALUES in output area before sending

PROBLEM: Messages don't appear
-------------------------------
SOLUTION:
□ Verify MSGO field is 40 characters
□ Check that messages are exactly as specified
□ Ensure LOW-VALUES is moved to output area before setting message
□ Verify SEND MAP command is executed

PROBLEM: Files downloaded in EBCDIC
------------------------------------
SOLUTION:
□ In IBM Developer, check transfer settings
□ Right-click connection → Properties → File Transfer
□ Ensure "Convert EBCDIC to ASCII" is enabled
□ Re-download files

PROBLEM: Can't find datasets on mainframe
------------------------------------------
SOLUTION:
□ Verify you're logged in as KC03FE1
□ Check dataset names are spelled correctly
□ Use ISPF 3.4 or Developer Data Sets view to search
□ Contact instructor if datasets don't exist

PROBLEM: Invalid characters in downloaded files
------------------------------------------------
SOLUTION:
□ This indicates EBCDIC encoding
□ Re-download with ASCII conversion enabled
□ Or use a conversion tool to convert EBCDIC → ASCII
