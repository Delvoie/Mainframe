================================================================================
              ASSIGNMENT 4 - CICS COMMANDS QUICK REFERENCE
                              KC03FE1
================================================================================

COPY THESE COMMANDS EXACTLY - JUST REPLACE FE1 WITH YOUR LAST 3 DIGITS

===============================================================================
STEP 1: CONNECT TO CICS
===============================================================================
CICS
(Press ENTER)

===============================================================================
STEP 2: DEFINE MAPSET
===============================================================================
CEDA DEFINE MAPSET(MNUSFE1) GROUP(DCMAFD02)
(Press ENTER, then PF5 to save)

===============================================================================
STEP 3: DEFINE PROGRAM
===============================================================================
CEDA DEFINE PROGRAM(99MNUFE1) GROUP(DCMAFD02) TRANSID(9FE1)
(Press ENTER, then PF5 to save)

===============================================================================
STEP 4: DEFINE TRANSACTION
===============================================================================
CEDA DEFINE TRANSACTION(9FE1) GROUP(DCMAFD02) PROGRAM(99MNUFE1)
(Press ENTER, then PF5 to save)

===============================================================================
STEP 5: DISPLAY YOUR RESOURCES
===============================================================================
CEDA DISPLAY GROUP(DCMAFD02) ALL(*FE1*)
(Press ENTER)

===============================================================================
STEP 6: INSTALL MAPSET
===============================================================================
CEDA INSTALL MAPSET(MNUSFE1) GROUP(DCMAFD02)
(Press ENTER)

===============================================================================
STEP 7: INSTALL PROGRAM
===============================================================================
CEDA INSTALL PROGRAM(99MNUFE1) GROUP(DCMAFD02)
(Press ENTER)

===============================================================================
STEP 8: INSTALL TRANSACTION
===============================================================================
CEDA INSTALL TRANSACTION(9FE1) GROUP(DCMAFD02)
(Press ENTER)

===============================================================================
STEP 9: TEST MAP DISPLAY
===============================================================================
CECI SEND MAP(MNUMFE1) MAPSET(MNUSFE1)
(Press ENTER - you should see your menu!)

===============================================================================
STEP 10: SET NEWCOPY (Load latest version of program)
===============================================================================
CEMT SET PROG(99MNUFE1) NEWCOPY
(Press ENTER)

===============================================================================
STEP 11: TEST YOUR TRANSACTION
===============================================================================
Clear screen, then type:
9FE1
(Press ENTER - menu should appear)

===============================================================================
IF YOU NEED TO UPDATE THE PROGRAM AFTER MAKING CHANGES
===============================================================================

After recompiling, run:
CEMT SET PROG(99MNUFE1) NEWCOPY
(Press ENTER)

Then test again with: 9FE1

===============================================================================
USEFUL TROUBLESHOOTING COMMANDS
===============================================================================

Check if program is installed:
CEMT INQUIRE PROGRAM(99MNUFE1)

Check if transaction is installed:
CEMT INQUIRE TRANSACTION(9FE1)

Check if mapset is installed:
CEMT INQUIRE MAPSET(MNUSFE1)

Display all your resources:
CEDA DISPLAY GROUP(DCMAFD02)

===============================================================================
COMMON ERRORS AND SOLUTIONS
===============================================================================

Error: "MAPFAIL"
Solution: CEDA INSTALL MAPSET(MNUSFE1) GROUP(DCMAFD02)

Error: "PGMIDERR" (Program ID Error)
Solution: CEDA INSTALL PROGRAM(99MNUFE1) GROUP(DCMAFD02)

Error: "TRANSIDERR" (Transaction ID Error)
Solution: CEDA INSTALL TRANSACTION(9FE1) GROUP(DCMAFD02)

Error: Old version of program running
Solution: CEMT SET PROG(99MNUFE1) NEWCOPY
