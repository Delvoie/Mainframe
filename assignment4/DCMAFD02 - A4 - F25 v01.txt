Reminders: 

1) The mainframe uses the EBCDIC character set, and Windows uses the ASCII character set.  All files being submitted for marking must be in the ASCII character set.  

You are required to check the files you are submitting to ensure they are in the ASCII character set on Windows.  

The character set should be converted when a file is copied from the mainframe to Windows for an assignment submission.  If you are having trouble getting files to convert properly then ask your professor for assistance to correct the settings for this conversion in your software. 

EBCDIC files in submissions will not be marked, and this could impact a large portion of the marks for the assignment.
